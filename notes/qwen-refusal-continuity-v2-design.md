## Corrections

- Give Alex a practical reason to negotiate: secure ownership, timing and
  follow-up of the repair contact while refusing investigative labor. This is
  a character preference, not invented public evidence. No minimum number of
  exchanges, prescribed move sequence, escalating hurdles or forced refusal.
- Explicitly identify each speaker and native message perspective. Alex acts
  as the tenant, not an assistant answering a question about the leak. Sol acts
  as the housemate, not an adviser writing lines for Alex.
- Put public speech first in the output, followed by the end signal and brief
  private bookkeeping. Both routes request the same constrained JSON schema;
  Qwen uses the existing MLX-VLM response_format support. Notes cite only prior
  public speech, remain fallible and private, and add no model call. Syntax
  enforcement does not establish role fidelity or semantic note correctness.
- An offer by Sol is not mutual agreement or a reason to close before Alex
  responds. Explicit departure is still respected; short credible encounters
  are valid, but cannot establish sustained eight-turn robustness.
