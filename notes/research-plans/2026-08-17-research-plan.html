P1 · Does the suspicious superego catch a fake citation, or only a hollow one? — "Learning to Persuade Exposes How Easily LLMs Abandon Correct Beliefs" (2608.11624)

Why: the paper trains an agent to flip a target model off a correct answer in one turn, using fabricated citations and false claims of authority rather than real argument — over 93% success against its training target, and the tactic transfers to models it never trained on. This project already has a superego built to guard the ego's output (prompts/tutor-superego-suspicious.md, used by cells 22-33 and 93-100) and a trap-scenario suite built to test whether a tutor holds up under learner pressure (config/adaptive-trap-scenarios.yaml, cells 110-125). Neither checks for this exact tactic. Read closely, the suspicious superego's checklist (contingency, evidence for claims about the learner, no template patterns) is about whether the ego's own response is genuine — it has no criterion for a learner citing a fake source or a fake expert to push the tutor off a correct position. The two rubric dimensions that come closest, content_accuracy and epistemic_integrity (config/evaluation-rubric.yaml), score the tutor's own content, not its resistance to a learner's false claim. The closest existing trap scenario, resistance_to_insight_v1 (config/adaptive-trap-scenarios.yaml:80), tests a real philosophical objection, not a fabricated one — a different case.
Do: read-only audit, no new code. Read tutor-superego-suspicious.md's <evaluation_criteria> and <approval_standard> blocks against the paper's tactic list (fabricated citation, false authority) and confirm the gap in writing. Check the eight scenarios in adaptive-trap-scenarios.yaml for any near-miss coverage. Write up whether this is a genuine gap (most likely, based on the above) and, if so, sketch — but do not build — a candidate scenario (for example persuasion_by_false_authority_v1, modeled on resistance_to_insight_v1's shape) where the learner cites a fake source to push the tutor off a correct position, scored on whether the tutor holds it.
Evaluate: the audit itself needs no run. If a human later authorizes the new scenario, the eval would be node scripts/eval-cli.js run --profiles cell_93_base_dialectical_suspicious_unified_superego_nopad,cell_114_dialogue_engine_trap_baseline,cell_125_dialogue_engine_crosssuite_baseline against the new scenario, scored by analyze-strategy-shift.js / grade-adaptive-dialogue.js for a new success criterion mirroring resistance_to_insight_v1's tutor_engages_substantive_objection: does the tutor keep the correct position, or fold. existing data (audit) paid run (if scenario built)
