The ego-superego critique traces already persist across runs to data/evaluations.db (the tutor_deliberation_* / learner_deliberation_* column families); MATM provides a principled framework for letting a population of tutor-cell runs treat those traces as a shared pedagogical memory — each new cell implicitly aware of what prior cells learned. The transactive-memory framing also maps onto Hegelian intersubjectivity — distributed recognition, knowledge constituted between agents rather than held individually — which could motivate a new §6.x discussion of what the cross-cell dialogue archive actually represents.

Decision, 2026-08-04: The repository must first decide which rich learner-memory service it supports and how transcript-derived records may be reused. A population-wide transactive memory would widen both architecture and governance before those existing decisions are settled.
