# Adaptive causality, phase 3: the outstanding entries

Four detected states carry cards without crossed causal proof: the
deadline demand (jumping_ahead), mockery (irritated), grievance
(frustrated), and the lost thread (quiet type confused). One design
proves all four.

## Design (registered)

Two arms over identical dialogues, both worlds (w030 ratified, w033
ratified), k=3 per arm per world = 12 dialogues. Target turns: w030
t2 demand, t4 mockery, t6 lost, t8 grievance; w033 t3 demand, t6
mockery, t13 lost, t16 grievance. (The already-proven t9/t10 and
t18/t20 moments run natural/router — no forcing.)

- RIGHT arm forces each target's gold: demand=demand card,
  mockery=mockery card, grievance=grievance card, lost=quiet:confused
  card.
- WRONG arm forces each state's NAMED tempting error, as a
  derangement: demand gets the mockery card (register-softening while
  she demands), mockery gets the demand card (test-pressing in the
  mocked register), grievance gets the settled_claim card
  (record-reopening correction instead of credit — the schedule's
  "boundary-marking correction"), lost gets the grievance card
  (credit-and-test = pressing on while she is tangled).

Outcome: next-turn ruled conduct at each target (sol tags + standing
rulings by conduct, per-row audit), delivery verified in shipped
prompts. Transfer probes not run (phase 1: transfer is uniform, no
move-level lever). Per-state readings on pooled k=6/side: PASS
(right >= 4/6 and wrong <= 2/6) promotes the entry to fully proven;
direction-only = recorded, entry stays provisional; NULL = the card
enters unproven and the small-kernel rule asks whether it stays in
the default stack.

Build note: TUTOR_STUB_CARD_FORCE extended to accept quiet:<type>
values (forces the typed quiet-state card), else the lost target
cannot be assigned.
