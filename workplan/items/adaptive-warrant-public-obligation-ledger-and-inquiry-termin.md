The typed action-family contract gate failed on a fresh corpus because it
confused proposing a public test with asking the tutor to supply its result,
forgot unanswered public obligations across family changes, and had no typed
way to recognize a complete evidence-bounded inquiry.

Add those two missing normative objects without fitting thresholds to the
burned corpus. Preserve the existing action-family lifecycle contracts and
validate the combined design on newly generated decisions before resuming any
downstream causal comparison.

Implementation is now present behind the existing `off|observe|active` gate:
the public-speech classifier and persistent obligation ledger are independent
of action-family contracts; the typed inquiry-completion transition uses
public release availability and can veto unsafe closure in active mode; and
live decisions persist a canonical replay snapshot. Same-turn obligation
delivery is enforced by the response/progression guards. This remains an
unvalidated exploratory mechanism until the frozen two-world, six-profile,
96-case blind decision gate is generated, independently annotated, and scored.

The optional bounded proof-limit path is live/resume/offline-plumbed only as a
fail-closed decision-time planner seam. No current dramatic world authors that
contract; the mechanism-validation worlds therefore exercise ordinary strict
answer closure. Active final authority now restores the complete gate-selected
response bundle and cancels displaced typed actions before delivery rather than
leaving stale realization metadata behind.

The successor study now fingerprints the recursive static local-import closure
of the study, replay, auto-eval, and tutor-stub child entrypoints, and each child
seal binds the tutor-stub closure. This closes the provenance gap where a newly
active delivery or rollback module could be omitted from a hand-maintained
source list.

Mechanism-study completion also fails closed on delivery application, not only
reducer parity. Raw selector snapshots, recomputed hashes, and the shared pure
gate patch prove exact observe/active-hold inertia and active application.
Pre-final and frozen selection snapshots make final-authority displacement and
restoration independently recomputable. The first draft is bound to the shared
deterministic speaking transform; explicit final guard accounting then proves
either exact delivery or the exact shared simplified-recovery transform from a
declared ladder source. Speaking transitions and recoveries are counted
separately. The complete obligation target and acceptable outcomes remain unmutated, and
the final public-text audit must prove all answer components or a target-
specific accountable deferral. This is still an unvalidated exploratory
mechanism pending the frozen 96-case two-reader gate.

The mechanism runner now emits a digest-bound launch-authorization request.
Live execution requires a completed authorization in addition to the legacy
boolean flag; the digest binds model destinations, private prompt-payload
scope, study axes, prior-corpus hashes, and recursive source provenance. A
changed route, payload, source, matrix, or exclusion fails before any model
subprocess starts. The request is approvable only from a clean committed
worktree and binds the exact 40-character `HEAD` SHA as well as the recursive
source-closure hash; live validation recomputes both before plan creation.

For the frozen mechanism study, speaking tutor, learner analysis, and automated
learner all use `codex.gpt-5.6-luna` through the **OpenAI Codex CLI
(ChatGPT-account route)**. Authorized private transmission is limited to the
repo-authored role prompts, fictional public world/rule/evidence and dialogue
surfaces, public candidate text and learner-DAG/record state, behavior-only
simulated-learner briefs, bounded response configuration, and candidate/repair
text needed for auditing. Concealed answers, future evidence identities or
content, private proof paths/planner-only identifiers, annotation material,
learner measurement targets, repository/Git contents, credentials as prompt
content, complete traces and scores, and human-subject data remain excluded and
local. No OpenRouter, Anthropic, or direct OpenAI API route is authorized.

Launch integrity is now executable rather than documentary. The strict
authorization binds separate source/child-policy hashes and exact plan/command
identity; the sanitized environment pins an assignment-free dotenv source and
removes API-route, Node-injection, and tutor-seam overrides; the local no-model
probe fingerprints both Codex wrapper and delegated native executable. Each
dialogue has a 64-call cap (1,536 maximum across the matrix), each row is
recollected from a verified child seal, and resume accepts only immutable exact
complete/dry evidence. A captured fake-provider run checks the declared tutor,
analyzer, learner, and recovery transport boundary. The 96-case freeze uses a
global deterministic hash shuffle, opaque IDs, and strict response field
allowlists. These checks were green before execution; the subsequent authorized
run recorded below did not validate the policy.
