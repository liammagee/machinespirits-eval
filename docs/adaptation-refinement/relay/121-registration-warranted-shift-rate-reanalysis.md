## 1. The question

Did the gate change the guarded learner's conduct on its own deficit —
shifting position with warrant?

The main block confirmed the gate-judgment endpoint (M1: gated 68.4%,
bare 61.8%, standing permission 53.2%). But both stored conduct
behaviors (result requests, proposed tests) came out flat in the free
split, and both are acts the persona's voice rules suppress ("minimize
uncertainty"). The learner's epistemic state is not pinned by those
rules: its commitments move against evidence, and the decision readers
already judged every such move. That judgment is the conduct measure
this note registers.

## 2. The measure, deterministic and already paid for

For each condition, over the main block's stored decision-reader data
(575 ruled cases, 463 with two-reader consensus):

> warranted-shift rate = consensus cases judged **warranted** / all
> consensus cases in that condition.

This regroups the same case list M1 used, by the condition field each
case already carries. No new instrument, no new reading, no call. It is
distinct from M1: M1 asked whether the **gate** agreed with the
readers; this asks what the readers said about the **learner**.

Reported beside it, description only: case counts and non-consensus
counts per condition, and a dialogue-grain summary (per-dialogue
warranted fraction, 24 dialogues per condition).

## 3. Prediction

**P-R1 (directional, single comparison):** the gated condition's
warranted-shift rate exceeds the bare rate and the standing-permission
rate.

Mechanism, written before looking: the challenge family fires on
defended shifts that lack warrant. A challenged learner either produces
a check or backs off the shift, so the shifts that stand in the gated
arm should carry warrant more often. A flat result is a finding: the
gate judges this learner well but does not change how it commits, and
the conduct cell stays null.
