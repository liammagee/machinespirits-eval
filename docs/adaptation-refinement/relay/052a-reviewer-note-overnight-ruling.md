## How the reviewer applies it

1. **Substantive FAIL is terminal.** Floors missed on clean,
   admissible data = the layer is cut; ruling 051 option 1 applies.
   No re-take, no threshold motion. This confirms registration §3.
2. **Technical or operational failure does not burn the attempt.**
   The r47 defect class: harness or transport breakage, schema or
   digest mismatch, provider quota death mid-run, assembly tooling
   bugs — anything where the instrument, not the reader, failed.
   Such a run is quarantined and disclosed, and a re-take is
   authorized, as many as needed.
3. **Classification duty.** Which class a failure falls in is the
   reviewer's ruling, made against the registered discriminator
   (STATE discipline point 2; ruling 004's stop rule) and disclosed
   in the relay before any re-take starts. Reader misses are data,
   never a technical failure.
4. **The 8,000-call ceiling holds.** Re-takes spend inside the
   ceiling the human set directly in the reviewer session. A re-take
   that would cross 8,000 is a hard stop for the human even under
   this ruling.
5. **Unattended overnight.** The reviewer continues without waiting
   for the human; the sibling session triangulates zero-call.
