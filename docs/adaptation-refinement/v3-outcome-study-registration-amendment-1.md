## Binding

1. **Scope — full injectable union.** The standing-permission text
   quotes EVERY instruction string the gate decision can cause to be
   injected, from the five sources SHA-pinned in report 056: the
   challenge-resistance catalogue description
   (`config/engagement-registers.yaml`), the first-draft cue
   (`services/tutorStubFirstDraftContract.js`), the stance, part,
   and tactic instructions selected downstream of the gate decision,
   and every question-support branch
   (`services/tutorStubQuestionSupport.js`). Nothing else.
2. **Form — a menu, not a paste.** Each quoted string appears
   byte-for-byte under one plain condition sentence. This keeps
   mutually exclusive branches coherent as standing text.
3. **Prefix rule — descriptive only.** Each condition sentence
   states only WHEN the gate would inject that string. It is one
   sentence, names the triggering state in plain words, and carries
   no imperative advice beyond the quoted string. The full prefix
   set is recorded in the A1 manifest and reviewed before the go
   note.
4. **Drift guard.** A guard diffs every quoted string byte-for-byte
   against its named source location at the pinned source SHAs; any
   drift is a hard stop.
5. **Review.** The second session reviews the exact bytes against
   the five SHA-pinned sources before the reviewer's go note.
